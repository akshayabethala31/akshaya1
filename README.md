# Diet Prediction System

A static web application that provides educational food recommendations
based on a user's profile and selected fitness goal.

## Features

- Gender, age, height and weight inputs
- BMI calculation
- Four fitness goals
- Food recommendations from a nutrition dataset
- Nutritional information and food cluster display

Built using HTML, CSS and JavaScript.
